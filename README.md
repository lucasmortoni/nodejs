# Node.js Study Repo

This repository is not a project in the usual sense.
It is a small collection of exercises and practice files for studying Node.js.

Each folder contains focused examples, experiments, and learning tasks meant to help understand how Node.js works in practice.

## Purpose

- Learn the fundamentals
- Practice JavaScript/Node.js concepts
- Explore small coding exercises
- Build understanding through repetition and examples

## Note

This is a study space, not a production app or finished project.

Happy coding! 🚀
